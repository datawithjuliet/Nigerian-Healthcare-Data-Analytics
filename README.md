# 🏥 Nigerian Healthcare Data Analytics Project

**An end-to-end data analytics project using SQL Server and Power BI.**

## 📊 Dashboard Preview

![Healthcare Data Analytics Dashboard](Dashboard/Healthcare_Dashboard.png)

## 👩‍💻 About the Project

My name is **Juliet Kashimana Akor**, and I have a background in Public Health. I developed this project to strengthen my skills in SQL, data analysis, data validation, and Power BI dashboard development.

The project explores a synthetic healthcare dataset, using SQL Server to examine and analyze the data and Power BI to present selected findings through an interactive dashboard.

## 🎯 Project Objectives

* Assess and clean healthcare-related data.
* Analyze patient demographics and diagnosis patterns.
* Explore patient-record counts across states.
* Examine monthly admission-record trends.
* Compare average length of stay across departments.
* Summarize recorded patient outcomes.
* Explore treatment costs and readmission records.
* Communicate findings through an interactive dashboard.

## 🛠️ Tools and Technologies

* SQL Server Management Studio (SSMS)
* SQL
* Microsoft Power BI
* DAX

## 🔍 Key Observations

* The cleaned dataset contains 4,988 records.
* The average recorded patient age is 45.3 years.
* The average recorded length of stay is approximately 5.5 days.
* Typhoid fever has the highest count in the displayed diagnosis chart.
* Oyo has the highest record count in the displayed state chart.

These observations describe the synthetic dataset and are not official Nigerian healthcare statistics.
